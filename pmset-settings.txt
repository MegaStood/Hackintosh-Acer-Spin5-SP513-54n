## How to apply this on a fresh setup
```bash
sudo pmset restoredefaults
sudo pmset -a hibernatemode 25
# verify persistence (CRITICAL — pmset -g lies if plist write fails):
ls -la /Library/Preferences/com.apple.PowerManagement*.plist
# expect: mtime updated to NOW, BOTH plists present
# if plists missing or mtime stale: reboot, then re-run pmset commands
```
