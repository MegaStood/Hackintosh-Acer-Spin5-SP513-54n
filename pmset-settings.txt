## Apply on a fresh setup
```bash
sudo pmset restoredefaults
sudo pmset -a hibernatemode 25

# CRITICAL — verify persistence (pmset -g lies if plist write failed):
ls -la /Library/Preferences/com.apple.PowerManagement*.plist
# expect: BOTH plists present, mtime updated to NOW
# if missing or stale: reboot, then re-run pmset commands
```

## Known caveats
- Hibernate-25 fires on battery (idle/clamshell sleep) and on AC (forced sleepnow).
- Idle sleep on AC behavior — not yet tested (probably DarkWake, not hibernate, per Apple AC policy).
- Power-source change mid-hibernate (battery → AC plug-in while asleep) suspected to trigger firmware wake bug 0x002A001F. Test pending.
- Wake reliably succeeds when waking on the same power source the system slept under.
